MÓDULO 1: AUTENTICAÇÃO E ONBOARDING WEB
--------------------------------------------------------------------------------

TELA 1.1: LANDING PAGE / PÁGINA INICIAL PÚBLICA
O QUE PRECISA TER:
1. Cabeçalho: Logo Xitique Digital, Menu [Funcionalidades] [Preços] [Contato] [Entrar]
2. Hero Section: Título "Digitalize seu Xitique em 5 minutos", Subtítulo "Substitua caderno e cartão", Botão "Começar Grátis" + Botão "Ver Demo"
3. Seção Problema: 3 cards com ícones - "Caderno perde" + "Cálculo erra" + "Fraude invisível"
4. Seção Solução: Screenshot app mobile + web lado a lado, texto "Collector na rua, você no escritório"
5. Seção Funcionalidades: Grid 6 cards - Offline, Anti-fraude, Relatórios, Empréstimo, Gamificação, API
6. Seção Preços: 3 planos - Básico 500 MZN/mês até 50 clientes, Pro 1500 MZN até 200, Enterprise custom
7. Seção Depoimentos: 3 cards "Ana Maputo: Reduzi 90% do tempo"
8. Rodapé: Links, Redes Sociais, Telefone +258
9. Botão WhatsApp flutuante canto inferior direito

POR QUÊ:
- Hero claro porque organizador chega com dor específica, precisa ver solução em 3s
- "Começar Grátis" trial 14 dias reduz fricção, organizador testa sem cartão
- Problema/Solução porque venda consultiva: primeiro dói, depois cura
- Screenshot lado a lado porque prova que existe mobile + web integrados
- Preços transparentes porque organizador calcula ROI antes de ligar
- WhatsApp flutuante porque público MZ prefere WhatsApp que email

O QUE PRECISA TER:
1. Step 1: Dados Organização - Nome grupo, Província dropdown, Cidade dropdown, Telefone +258
2. Step 2: Dados Owner - Nome completo, Email, Senha forte indicador
3. Step 3: Plano - Radio Básico/Pro/Enterprise, Mostra limite clientes
4. Step 4: Resumo + Checkbox "Aceito Termos" + "Aceito LGPD"

6. Texto "Aguardando aprovação" após submit

POR QUÊ:

- Província/Cidade cascata porque System Owner segmenta suporte
- Senha forte indicador porque organizador guarda dinheiro de terceiros
- "Aguardando aprovação" porque não é auto-serviço, evita fraude, System Owner valida se é xitique real
- Protocolo porque organizador cobra "cadê meu cadastro?"
