VISÃO GERAL MOBILE
--------------------------------------------------------------------------------
O app mobile tem 2 perfis principais que usam diariamente:
1. COLLECTOR - Agente de campo, usa tablet/celular na rua, 100% offline
2. TICANTE - Cliente final, usa para consultar, opcional

Organizador usa mobile para consulta rápida, mas gestão pesada é na Web.

FLUXO DE ENTRADA: 3 CAMINHOS
--------------------------------------------------------------------------------
Quando pessoa baixa app pela primeira vez, tela inicial tem 3 botões grandes:
1. [QUERO SER ORGANIZADOR] - Cria grupo de xitique
2. [QUERO SER CLIENTE/TICANTE] - Entra em grupo existente  
3. [JÁ TENHO CONTA] - Login para quem já está cadastrado

PARTE 1: FLUXO DE CADASTRO ORGANIZADOR
================================================================================

TELA 1.1: SPLASH + ESCOLHA INICIAL
O QUE PRECISA TER:
1. Logo Xitique Digital centralizado
2. Animação Lottie de cofre enchendo
3. Após 2s, mostra 3 botões verticais:
   Botão 1: Ícone prédio + "Quero ser Organizador" + Subtexto "Criar meu grupo de xitique"
   Botão 2: Ícone pessoa + "Quero ser Cliente" + Subtexto "Entrar em grupo existente"
   Botão 3: Ícone chave + "Já tenho conta" + Subtexto "Fazer login"
4. Link rodapé "Termos de Uso"

POR QUÊ:
- 3 botões claros porque usuário novo não sabe o que é "organizador" vs "ticante"
- Animação cofre porque vende conceito em 2s
- Subtexto explica em linguagem simples
- Termos link porque LGPD exige antes de coletar dado

TELA 1.2: CADASTRO ORGANIZADOR - STEP 1 DADOS ORGANIZAÇÃO
O QUE PRECISA TER:
1. Barra progresso: Passo 1 de 4
2. Título "Dados do seu Grupo"
3. Input "Nome do Grupo" obrigatório, placeholder "Ex: 3o Bairro, Casa N23, Q30, B10"
4. Dropdown "País" fixo "Moçambique" desabilitado
5. Dropdown "Província" obrigatório: Maputo, Gaza, Inhambane, Sofala, Manica, Tete, Zambézia, Nampula, Cabo Delgado, Niassa
6. Dropdown "Cidade/Distrito" obrigatório, filtra por província
7. Input "Telefone da Organização" +258 fixo + 9 dígitos
8. Upload "Logo do Grupo" opcional, preview circular
9. Botão "Próximo" desabilitado até preencher obrigatórios

POR QUÊ:
- 4 steps porque formulário longo assusta, dividir reduz abandono
- País fixo porque MVP só MZ, mas arquitetura prepara expansão
- Província dropdown porque padroniza, evita "Maputo" vs "maputo" vs "Mapto"
- Cidade filtra por província porque Maputo tem distritos diferentes de Nampula
- Telefone +258 fixo porque evita erro DDI
- Logo opcional porque org pequena não tem, mas se tem usa em PDF
